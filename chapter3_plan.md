# План Главы 3. Реинжиниринг бизнес-процессов структурных подразделений КФУ

---

## 3.1. Анализ текущего состояния бизнес-процессов подразделений (AS IS)

### 3.1.1. Связь показателей подразделений с результатами отраслевого анализа вузов
- Привязка деятельности подразделений к стратегическим показателям КФУ из Главы 2 (кадровый потенциал → ЦРКП; инфраструктура и цифровизация → УДК; научно-образовательная среда и международная деятельность → Дирекция музеев)
- Обоснование выбора подразделений для реинжиниринга через показатели мониторинга

### 3.1.2. Дирекция музеев КФУ — текущее состояние процессов
- **IDEF0** (контекстная + 1 уровень декомпозиции): «Управление музейным фондом» — верхнеуровневый процесс (входы: экспонаты, заявки на экскурсии; выходы: каталогизированный фонд, проведённые экскурсии; механизмы: КАМИС, сотрудники; управление: регламенты Минкультуры, требования госкаталога)
- **BPMN AS IS**: «Регистрация и описание музейных экспонатов в КАМИС» — проблемный процесс (45 мин/экспонат, ручные операции, зависания, отсутствие шаблонов)
- **EPC AS IS**: Детализация проблемных зон — фотосъёмка, ручной ввод данных, выгрузка в госкаталог (маркировка узких мест: ожидание 10 мин, зависание ПО, лишние перемещения)

### 3.1.3. Центр развития кадрового потенциала (ЦРКП) — текущее состояние процессов
- **IDEF0** (контекстная + 1 уровень декомпозиции): «Управление кадровыми процессами КФУ» — верхнеуровневый процесс (конкурсный отбор ППС, подбор персонала, формирование графика отпусков, отчётность)
- **BPMN AS IS**: «Формирование графика отпусков ППС» — проблемный процесс (от 5 дней на обработку заявления, 40 часов/месяц на транспортировку, 192 мин совокупных потерь)
- **EPC AS IS**: Детализация проблемных зон — многократное хождение за подписью проректора, бумажный документооборот, отсутствие уведомлений о готовности документов

### 3.1.4. Управление документооборота и контроля (УДК) — текущее состояние процессов
- **IDEF0** (контекстная + 1 уровень декомпозиции): «Управление документационным обеспечением КФУ» — верхнеуровневый процесс (регистрация входящих/исходящих, согласование ОРД, архивное обслуживание)
- **BPMN AS IS**: «Исполнение запросов граждан в архиве» / «Регистрация входящих писем» — проблемные процессы (22 мин на справку, 176 сек на регистрацию, поиск в бумажном архиве)
- **EPC AS IS**: Детализация проблемных зон — ручной поиск в архиве (только 12% оцифровано), лишние движения при регистрации, многократные итерации согласования ОРД (7 часов ожидания)

### 3.1.5. Сводный анализ потерь и проблемных зон
- Таблица потерь (MUDA) по подразделениям
- Диаграмма Ишикавы (обобщённая) по корневым причинам
- Классификация операций CVA/BVA/NVA

## 3.2. Проектирование целевых процессов (TO BE)

### 3.2.1. Дирекция музеев — целевые процессы
- **BPMN TO BE**: «Регистрация экспонатов в КАМИС» — оптимизированный процесс (шаблоны карточек, стандартизированная фотозона, привлечение лаборанта, 18 мин/экспонат вместо 45)
- **EPC TO BE**: Акцент на изменениях — устранение ожидания выгрузки, автоформы в КАМИС, офлайн-шаблоны, 5S на рабочем месте
- Сравнительная таблица показателей AS IS vs TO BE (время цикла, производительность, количество экспонатов/день)

### 3.2.2. ЦРКП — целевые процессы
- **BPMN TO BE**: «Формирование графика отпусков ППС через Битрикс24» — электронное согласование, уведомления, единый приказ вместо пачки заявлений (с 5 дней до 1 дня)
- **EPC TO BE**: Акцент на изменениях — электронная подпись, автоматическое формирование списков, push-уведомления о приближении отпуска, исключение транспортировки
- Сравнительная таблица показателей AS IS vs TO BE (трудоёмкость: с 20 до 3 сотрудников, время обработки: с 135 мин до 20 мин)

### 3.2.3. УДК — целевые процессы
- **BPMN TO BE**: «Исполнение запросов граждан (оцифрованный архив)» / «Регистрация входящих с разделением экрана»
- **EPC TO BE**: Акцент на изменениях — электронный поиск вместо физического (с 22 до 14 мин), исключение распечатки при регистрации, QR-коды для исходящих, сокращение итераций согласования
- Сравнительная таблица показателей AS IS vs TO BE

### 3.2.4. Обобщение целевых изменений
- Сводная таблица трансформации по всем подразделениям
- Связь улучшений с показателями мониторинга из Главы 2 (повышение эффективности кадрового потенциала, инфраструктуры, цифровизации)

## 3.3. Оценка экономической эффективности реинжиниринга

### 3.3.1. Обоснование инвестиций
- Структура инвестиционных затрат по подразделениям:
  - Музеи: оборудование + найм лаборанта (~ежемесячные расходы + единоразовые)
  - ЦРКП: внедрение Битрикс24 (~5 000 000 руб. первый год, далее 4 788 000 руб./год)
  - УДК: оцифровка архива (SSD + OCR + студенты), QR-система (52 500 руб.), второй монитор
- Общий инвестиционный бюджет проекта

### 3.3.2. Расчёт денежных потоков и эффектов
- Ежегодная экономия по подразделениям:
  - Музеи: рост производительности в 3.3x, экономия через эффективное использование рабочего времени
  - ЦРКП: экономия 5 608 000 руб./год (сокращение потребности с 20 до 3 сотрудников)
  - УДК: 27 342 руб./мес + 480 000 руб./год (эффект оцифровки) ≈ 808 000 руб./год
- Совокупный годовой экономический эффект

### 3.3.3. Расчёт NPV (чистой приведённой стоимости)
- Горизонт планирования: 5 лет
- Ставка дисконтирования: обоснование (ключевая ставка ЦБ + премия за риск)
- Расчёт NPV для каждого подразделения и совокупный NPV проекта

### 3.3.4. Расчёт IRR (внутренней нормы доходности)
- IRR для совокупного проекта
- Сравнение IRR со ставкой дисконтирования — вывод о целесообразности

### 3.3.5. Дисконтированный срок окупаемости (DPP)
- Расчёт по годам (нарастающим итогом дисконтированных потоков)
- Графическое представление (таблица по годам)

### 3.3.6. Точка безубыточности
- Определение минимального объёма операций (документов/экспонатов/заявлений), при котором экономия покрывает текущие затраты на поддержание систем
- Анализ чувствительности: при каком снижении объёмов операций проект перестаёт быть рентабельным

### 3.3.7. Сводная оценка и выводы
- Сводная таблица инвестиционных показателей (NPV, IRR, DPP) по каждому подразделению и в целом
- Обоснование приоритетности внедрения (ЦРКП → УДК → Музеи по размеру эффекта)
- Связь результатов с целевыми показателями цифровой трансформации вуза
