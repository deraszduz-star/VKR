# Структура отчета по преддипломной практике

1. **Титульный лист.**

2. **Содержание.**

3. **Введение** (в котором должны быть отражены время, место, срок и цели прохождения практики).

4. **Раздел 1. Постановка цели и задач исследования** (в данном разделе обучающийся должен сформулировать цель и задачи выпускной квалификационной работы, описать объект и предмет исследования).

5. **Раздел 2. Анализ предметной области объекта исследования** (в данном разделе обучающийся должен собрать материалы, необходимые для написания выпускной квалификационной работы (используя современные информационные технологии и электронные базы данных, Интернет), а также провести анализ полученных данных, выявить проблемы в исследуемой области (используя современные методы сбора, анализа, моделирования и обработки научной информации)).

6. **Раздел 3. Выводы по итогам проведенного исследования** (в данном разделе обучающийся должен сформулировать выводы по итогам исследований и лаконично оформить результаты работы).

7. **Заключение** (выводы по проделанной работе). **Список использованных источников.**

8. **Приложения.**
