# Нотации описания бизнес-процессов

Папка содержит структурированные конспекты трёх нотаций моделирования бизнес-процессов и функций систем, подготовленные на основе первоисточников.

| Файл | Нотация | Источник |
|---|---|---|
| [`IDEF0_notation.md`](IDEF0_notation.md) | IDEF0 (Integration DEFinition for Function Modeling) | FIPS PUB 183, NIST, December 21, 1993 (`../idef0.pdf`) |
| [`BPMN_notation.md`](BPMN_notation.md) | BPMN 2.0 (Business Process Model and Notation) | OMG document `formal/2011-01-03`, January 2011 (`../formal-11-01-03.pdf`) |
| [`EPC_notation.md`](EPC_notation.md) | EPC (Event-Driven Process Chain) | [Business Studio. Help — Нотация EPC](https://www.businessstudio.ru/help/docs/current/doku.php/ru/csdesign/bpmodeling/epc_notation) |

## Состав конспектов

Каждый файл включает:

- общее описание назначения нотации и её области применения;
- терминологический глоссарий;
- описание графических элементов и их семантики;
- правила построения диаграмм и связи между элементами;
- памятку для практика.

## Как читать

- **IDEF0** — для иерархического функционального моделирования "сверху вниз" (стрелки = ограничения, не поток).
- **BPMN 2.0** — для детального процессного моделирования, в т.ч. исполнительных процессов и взаимодействий между участниками.
- **EPC** — для описания процессов нижнего уровня в виде чередующихся событий и функций с явной логикой через AND/OR/XOR.
